# 启晨教育产品说明

本文件记录用户已经确认的要求和仍待确认的事项。代码现状不自动等同于正确需求。

## 已确认：产品与角色

- 产品名称为“启晨教育”，正式方向为微信小程序。
- 学生/普通用户：浏览和购买课程、查看课表、申请请假、完成同步学练、获得和兑换积分、使用小启助手、查看订单。
- 教师：展示教师资料、荣誉和教学成绩；审批本人课程的请假申请。
- 管理/运营角色：用户未确认完整后台范围，但已确认需要配置 AI 语气和常见问题答案。

## 已确认：功能范围

### 首页

- 顶部展示热门课程横向滚动列表。
- 展示我的课表，包括时间、教室和任课教师。
- 提供请假入口和小启助手入口。

### 课程

- 课程包括新概念一、新概念二、同步课程、入门 A、入门 B、音标、初级语法、高级语法、高思数学三年级、高思数学四年级。
- 详情包含课程介绍、价格和教师介绍。
- 教师专页包含荣誉和教学成绩。
- 支持课程和教师模糊搜索；按教师搜索时展示该教师教授的课程。

### 请假

- 学生选择请假课程和时间并填写申请。
- 由该课程教师审批。
- 审批至少包含同意和拒绝。

### 同步学练与积分

- 包含英语单词和数学加减法练习。
- AI 自动批改；满分获得积分。
- 积分可兑换礼物。

### 我的与订单

- 展示已购课程和订单。
- 展示积分和兑换入口。
- 提供退出登录。

### 小启助手

- 通过云函数安全连接 DeepSeek，API Key 不得暴露在小程序端。
- 可配置说话语气和常见问题答案。
- 支持连续对话。
- 称呼应来自当前用户资料或随机身份，不能写死为“林同学”。
- 游客不能使用需要保存学习记录的助手功能，应引导登录。

## 已确认：登录与资料规则

- 用户协议和隐私政策默认不勾选，用户必须主动勾选；未勾选时登录和游客体验均需提示。
- 登录页提供“登录后使用我的微信头像和昵称（可在资料页替换）”选项。
- 勾选时：用户主动选择微信头像/昵称，并可以在资料页替换。
- 不勾选时：系统生成随机名称和随机头像，并覆盖同一微信账号以前保存的展示姓名和头像，不能沿用旧资料。
- 已登录且没有主动退出的用户，再次打开时直接进入首页。
- 从未登录或主动退出的用户，再次打开时先进入登录页。
- 资料页支持相册选择、替换和移除头像；保存后应立即显示新结果。

## 核心流程

### 登录

```text
主动勾选协议
→ 选择是否使用微信头像和昵称
→ 微信身份登录并获得 OpenID
→ 勾选：确认或修改资料
→ 未勾选：覆盖旧展示资料并生成随机身份
→ 保存登录状态
→ 进入首页
```

### 请假

```text
选择课程、日期并填写原因
→ 创建 pending 申请
→ 对应教师审批
→ approved 或 rejected
→ 学生查看结果
```

### AI 对话

```text
登录用户提问
→ chat 云函数读取配置与 FAQ
→ FAQ 命中则直接回答，否则调用 DeepSeek
→ 返回回答并按规则保存记录
```

## 决策记录

- 2026-10：正式方向由网页原型改为微信小程序，原因是用户明确不需要网页版。
- 2026-10：协议由自动同意改为默认不勾选、必须主动确认，原因是用户提出安全要求。
- 2026-10：登录资料选项由“是否使用微信头像”改为“是否使用微信头像和昵称”；未勾选时生成随机身份并覆盖旧展示资料。该规则替代“未勾选头像但继续沿用旧姓名”的旧行为。
- 2026-10：小启称呼由固定“林同学”改为当前用户名称。
- 用户曾要求“真实姓名必填”，随后又确认可使用微信昵称或随机名称。最新显示身份规则采用微信昵称/随机名称；教学管理是否仍需单独保存经核验的真实姓名，尚未确认。

## 尚未确认

- 学生、教师和管理员是否共用一个小程序，或教师/管理员使用独立后台。
- 是否需要独立的真实姓名字段及其核验方式、展示范围和隐私规则。
- 退出登录是仅清除本地状态，还是也应删除或匿名化云端资料。
- 课程、班级、排课、教师与学生的正式数据模型。
- 订单退款、取消、有效期和转课规则。
- 积分奖励数值、防刷、过期和兑换履约规则。
- 请假截止、撤回、重复申请、补课和审批超时规则。
- AI 每日额度、内容审核、家长控制、记录保存期限和删除机制。
- 教师荣誉与成绩的审核、发布和隐私规则。
