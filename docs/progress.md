# 启晨教育开发进度

更新时间：2026-10-27

## 状态定义

- **已实现（本地）**：工作区存在相关代码。
- **已验证**：有明确的检查或运行证据。
- **未验证**：不能仅从代码推断运行成功。
- **需求已确认**：用户明确要求，不代表实现已验收。

## 当前概况

- 正式项目目录为 `miniprogram/`；根目录网页文件是早期原型。
- 当前目录不是 Git 仓库。
- 公开配置 `miniprogram/project.config.json` 使用 `touristappid`；真实 AppID 存放在被 `miniprogram/.gitignore` 忽略的 `project.private.config.json`，公开项目时不得强制提交该私有文件。
- `miniprogram/app.js` 使用具体云环境，而 `cloudbaserc.json` 仍含占位配置，环境配置不一致。
- PowerShell 读取部分中文文件时出现乱码；尚未确认是终端显示编码还是源文件损坏，需在微信开发者工具中检查。
- 本次仅整理文档，没有修改业务代码、部署云函数或进行真机测试。

## 数据与配置

代码或既有说明涉及集合：`users`、`courses`、`teachers`、`leave_requests`、`orders`、`points_ledger`、`ai_settings`、`chat_messages`。无法从本地确认它们是否已全部创建、权限是否正确或数据是否有效。

本地登录状态使用：

- `qichen_logged_in`
- `qichen_user`

用户资料字段目前包括：

- `realName`、`nickname`
- `avatarUrl`、`avatarEmoji`、`avatarColor`
- `identityType`（`random` / `custom`）
- `profileCompleted`、`realNameSetByUser`

这些字段经过多次规则调整，旧用户数据可能与新逻辑冲突，需要正式迁移方案。

## 实际验证证据

- 可使用 `node --check` 检查 JavaScript 语法。
- 可使用 Node 解析主要 JSON 文件。
- 当前各云函数 `package.json` 声明了 `main` 和 `wx-server-sdk`。
- 以上检查不覆盖 WXML/WXSS 编译、授权、云存储、数据库、云函数部署和真机行为。

历史调试中曾出现：

- 云函数缺少 `wx-server-sdk`。
- `chat` 云函数 3 秒超时。
- 云端 `updateProfile` 仍执行旧版姓名校验。
- 退出后沿用旧姓名/头像，以及新头像未覆盖旧头像。

本地已有针对性修改，但没有当前云端部署与真机复测证据，因此不能标记为已解决或已验收。
